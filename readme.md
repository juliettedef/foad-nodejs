# User API

Pour lancer le projet localement, suivez ces étapes :

Ouvrez un terminal et placez-vous dans le dossier du projet : cd foad30oct

Assurez-vous que Docker Desktop est lancé

Construisez et démarrez les conteneurs : docker compose up -d

Une fois le serveur lancé, ouvrez votre navigateur à l’adresse suivante : http://localhost:8080/api/users
